## 📱 WhatsApp Ordering Workflow

### A. Quick 1-Click WhatsApp Order
Every dish card features an **"Order Now"** button with the WhatsApp logo. Clicking it immediately opens WhatsApp (`098851 96008`) with a pre-written, formatted message for that specific dish and portion size!

### B. Multi-Item Cart & Checkout Drawer
1. Customer clicks **"Add to Cart"** on one or multiple dishes and portions.
2. The interactive **Cart Drawer** allows:
   - Increasing/decreasing quantities.
   - Selecting **No-Contact Home Delivery**, **Takeaway (Self-Pickup)**, or **Dine-in (Table Order)**.
   - Entering Customer Name, Phone, and Address (or Table Number).
   - Adding Special Cooking Notes (e.g. *"Extra spicy"*, *"No coriander"*, *"Extra garlic toum"*).
3. Clicking **"Place Order via WhatsApp 💬"** automatically formats a complete bill and order receipt:
   ```text
   🕌 *NEW ORDER - ARABIAN CORNER RESTAURANT & SKYLOUNGE* 🕌
   📍 _Gachibowli, Hyderabad (Venkat Sai's Ganapathi Gold)_
   ----------------------------------------
   👤 *Customer Name:* Rahul Sharma
   📞 *Customer Phone:* 9885196008
   🔖 *Order Type:* 🛵 Home Delivery
   📍 *Delivery Address:* Flat 402, Gachibowli, Hyderabad

   📋 *ORDER ITEMS:*
   1. *Chicken Faham Mandi* (Full Platter)
      ↳ Qty: 1 × ₹780 = *₹780*

   2. *Signature Cheese Kunafah* (Classic Cheese)
      ↳ Qty: 2 × ₹290 = *₹580*

   3. *Artisan Garlic Naan* (1 Piece)
      ↳ Qty: 3 × ₹60 = *₹180*

   ```
4. WhatsApp Web or the WhatsApp Mobile App launches directly with the restaurant owner's chat at `098851 96008`, where the owner confirms and starts preparation!

## 🚀 How to Run & Deploy

### Quick Local Preview
1. Simply double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox!
2. Or run with Node:
   ```bash
   npm start
   ```

- **Netlify**: Drag and drop the `ARABIAN RESTUARENT` folder into [Netlify Drop](https://app.netlify.com/drop).
- **GitHub Pages**: Push this folder to a GitHub repository and enable GitHub Pages in repo settings.
- **Vercel**: Deploy directly using `vercel deploy`.
